# Computer Vision (ELL7293)

## Assignment 1

### Task 1: Camera Calibration
Implementation of monocular and stereo camera calibration, estimation of intrinsic and extrinsic parameters, image rectification, feature matching using SIFT and ORB, and disparity map generation using SGBM.

### Task 2: Lane Boundary Detection
Implementation of lane boundary and lane curvature detection from road images, including preprocessing, lane extraction, curvature estimation, and result visualization.

## Assignment 2

### Task 1: Object Detection in Satellite Imagery
Fine-tuning and evaluation of YOLO11 models on the DOTA aerial imagery dataset for object detection. The task includes dataset preprocessing, image tiling, hyperparameter optimization, model training, and performance analysis.

### Task 2: Fréchet Inception Distance (FID)
Implementation of the Fréchet Inception Distance (FID) metric for evaluating the quality of generated images using InceptionV3 feature representations and statistical distribution comparison.

### Task 3: Transformers
Implementation and analysis of Transformer-based architectures, including training a Tiny-BERT model, pretraining, fine-tuning, and performance evaluation on downstream tasks.
